Download the full ZIP instead

Existing installSelect your existing BernAPlan/index.html in the save dialog and confirm replacement. Export a JSON backup first.
Protect your data. BernAPlan stores your plan in browser local storage. Before updating, open the current app and use Backups → Export JSON backup. Keep the backup somewhere safe and update the existing file in the same location to help preserve your data.
Windows security stays on. This package is designed to open through your browser. It does not require PowerShell, a CMD installer, administrator access, or changes to Smart App Control.
